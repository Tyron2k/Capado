# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| latest  | ✅        |
| < latest | ❌       |

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not** open a public issue.

Instead, please report it privately via GitHub's
[Security Advisories](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
feature on this repository.

This is a personal project maintained in my free time. I will do my best to
address security issues promptly, but I cannot guarantee specific response
times. Critical issues will be prioritized.

## Scope

- Authentication and authorization bypass
- SQL injection or other injection attacks
- Cross-site scripting (XSS)
- Sensitive data exposure
- Privilege escalation
